# 字体来源记录

自托管字体文件,通过 Fontshare 公开 CSS API (`https://api.fontshare.com/v2/css`) 于 2026-08-14 获取。三款均为 Indian Type Foundry 在 Fontshare 上发布的免费商用字体。

| 文件 | Family | Weight | Format |
|---|---|---|---|
| `satoshi-400.woff2` | Satoshi | 400 (Regular) | woff2 |
| `satoshi-500.woff2` | Satoshi | 500 (Medium) | woff2 |
| `satoshi-700.woff2` | Satoshi | 700 (Bold) | woff2 |
| `cabinet-grotesk-700.woff2` | Cabinet Grotesk | 700 (Bold) | woff2 |
| `clash-display-600.woff2` | Clash Display | 600 (Semibold) | woff2 |
| `clash-display-700.woff2` | Clash Display | 700 (Bold) | woff2 |

页面中出现的 `font-weight: 650` 无对应静态字重文件,由浏览器按 CSS 字重匹配算法自动落到最近的已声明字重(700)渲染,不影响可读性。
