动效语法

整套系统只有一条缓动曲线。动效的职责是让内容的到达显得从容,而不是让页面看起来很忙——动效要完成动作,不要持续呼吸。页面上没有任何无限循环的装饰性动画。

Easing

field-ease cubic-bezier(0.2, 0, 0, 1)
CustomEase.create("field-ease", "0.2,0,0,1")
gsap.defaults({ ease: "field-ease" })

前段几乎立即启动,后段长距离减速收尾。所有 CSS 过渡与 GSAP 补间共用它,唯二例外是进度条(ease: none,必须线性反映滚动位置)和数字递增(power2.out)。

Duration

时长用于为什么
200–280ms交互反馈协议项选择、按钮描边、展开标记旋转。快到不被察觉为"动画",只被感觉为"响应"。
360ms节点状态信号节点的缩放与描边。比纯反馈略慢,因为它同时改变了三个属性。
500ms列表瀑布列表项逐条到达,单项 0.5s、间隔 0.07s。
640ms章节揭示整章内容进入视口。全站最慢的一次性动作,每章只触发一次。
600ms一次性涟漪选中节点时圆环的单次响应。不循环。
1.2s环境光晕区块背景光晕的位移与显影,慢到不构成干扰。

Rules

01动效要完成动作,不要持续呼吸。没有无限循环的装饰动画。选中反馈是一次性涟漪,不是脉冲。
02只动 transform 和 opacity,以及 CSS 变量驱动的渐变位置。不在滚动帧里改布局属性。
03章节揭示 每章只触发一次(once: true),回滚不重放——重复播放会让页面显得廉价。
04连续值(指针位置、滚动进度)不经过组件状态,直接写入 CSS 变量或 transform。离散状态只在动作结束时提交一次。
05动效是渐进增强。动效层加载失败时,内容停在完全可见的静态状态,页面依然完整可读。
06prefers-reduced-motion 下移除所有非必要动效,但保留进度条——它传达的是真实位置,不是装饰。
